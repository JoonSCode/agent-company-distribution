# Optional Planning Lenses

Use only a lens that resolves a live planning uncertainty; skip the rest.
Reuse the current plan and contract, not parallel maps or new reporting fields.
These are Company adaptations of sources checked in the supplied research on
2026-10-26, not validated prompts or execution authority.

| Lens and source | Use / skip | Benefit, limit, and reversal evidence |
| --- | --- | --- |
| [Shape Up](https://basecamp.com/shapeup) | Use when uncertain solution detail is causing premature tickets; skip a shaping exercise for an exact settled edit. | Separate the approved investment bound, essential outcome and non-goals from implementation tactics. Do not import a fixed cycle or cut acceptance to fit it; revisit when feasibility evidence shows the outcome cannot fit the approved bound. |
| [Story mapping](https://jpattonassociates.com/story-mapping/) | Use when a plan delivers technical layers but no usable journey; omit a separate map when the existing topology already proves the end-to-end outcome. | Exposes missing user steps and a coherent first slice. A journey is not a state or dependency model; revise the slice when an actual consumer, recovery path or must-preserve state is absent. |
| [Example mapping](https://cucumber.io/docs/bdd/example-mapping/) | Use when owners interpret an acceptance rule differently; skip when the rule and oracle are already unambiguous. | A concrete case can reveal a hidden rule without a longer specification. Examples do not prove completeness; a contradictory boundary case or unresolved product choice reopens the affected criterion with its owner. |
| [Rolling-wave planning](https://www.pmi.org/-/media/pmi/documents/public/pdf/certifications/practice-standard-scheduling.pdf) | Use when distant detail depends on upcoming evidence; skip deferral for fixed external dependencies or known high-risk boundaries. | Keeps near-term work actionable without fictional precision. Do not defer required closure or emit an unstartable leaf; refine later proposals when prerequisite output arrives or a dependency deadline makes detail decision-relevant. |
