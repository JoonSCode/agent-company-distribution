# Release notes

## v0.2.0 — 2026-10-25

- Standalone Orca Company uses Orca Task/Dispatch without a King Sejong Core
  checkout, installation, pin, identity or execution subprocess.
- Interactive terminal setup and prompt-free setup use the transactional
  installer with persistent source identity, update, recovery, rollback and
  uninstall. Private configuration and user-owned additions remain protected.
- Markdown configuration supports single/multiple presets and explicit provider
  choices. Fresh public defaults keep the updater and API-paid execution OFF.
- Claude Code selection provides an explicit owned `/agent-company` skill entry;
  other supported routes still require host, authentication and model checks.
- The public runtime projection excludes private evaluation inputs and private
  source history. Existing public v0.1.0 history and release remain preserved.

Verification covers deterministic source/projection checks and file installation
lifecycle tests in isolated homes. These checks do not certify live Claude
sign-in, discovery, model behavior, native hook trust or product/business results.
No provider sign-in or paid API call is performed by setup.
